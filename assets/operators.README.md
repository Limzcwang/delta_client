# operators.json 数据说明（三角洲行动 技能配置）

> 生成时间：2026-10-20　｜　版本：**S11「群星」**（2026-09-04 上线，含 2026-09-17 平衡补丁）
> 口径：**烽火地带**（摸金模式）；全面战场部分干员大招 CD 不同，见文末。

## 1. 文件与字段

- 数据文件：`assets/operators.json`（客户端内置配置，UTF-8，无注释）
- 字段：`id`（拼音，模板文件名用）、`name`（面板显示）、`avatar`（头像模板路径）、`skills[3]`
- 槽位固定：`slot 0 = 大招(X)`、`slot 1 = 战术技能(V)`、`slot 2 = 投掷物/装备(G)`
- `total_cd_ms`：**单次充能所需毫秒**；有充能的技能配 `max_charges` 使用（如激素枪 30000ms × 6 发）
- 大招的 `total_cd_ms` 是「0→100% 充满」的时间；HUD 读到的百分比按 `(100-pct)% × total_cd_ms` 换算

## 3. 已知缺口（5 个槽位无秒数，`total_cd_ms: null`）

| 干员 | 槽位 | 技能 | 原始资料写法 |
|---|---|---|---|
| 无名 | 2 | 闪光弹 | 「数量：2颗（CD回复）」 |
| 牧羊人 | 2 | 震撼手雷 | 「数量：X颗」 |
| 乌鲁鲁 | 2 | 复合型燃烧弹 | 「数量：2颗」 |
| 比特 | 0 | T仔追踪爆破 | 「大招充能」 |
| 银翼 | 0 | 蜂鸟间谍摄像头 | 「大招充能」 |

这 5 条**不要瞎填**：客户端遇到 null 应跳过该槽位的遮罩比例换算（或只显示充能数/百分比原文）。
进游戏实测一次即可补齐（读到百分比从 0→100% 的用时，四舍五入到秒）。

## 4. 本版已应用的版本修正

- **麦晓雯** 信号破译器：120s → **90s**（S11 赛季更新）
- **旅人** 军犬协同：120s → **90s**（烽火；全面战场 75s，2026-09-17 补丁）
- **深蓝** 防爆套装：45s → **60s**（S8 起）
- **深蓝** 刀片刺网手雷：35s、上限 1（S8：55s/2 个 → 35s/1 个）
- **威龙/疾风**：2026-09-17 仅修了「击倒减 CD 异常」的 BUG，基础 CD 未变

## 5. 槽位判定的两处坑（已按游戏内键位纠正）

- **蜂医**：`X` 是**激素枪**（治疗/6 发充能），`V` 是**烟幕**无人机，`G` 是蜂巢科技烟雾弹。
  初版把烟幕当大招是错的（依据：[九游·蜂医技能解析](https://www.9game.cn/sjzxd/10541108.html)「点击 X 切换激素枪」「按 V 扔出烟雾无人机」）。
- **银翼**：BWIKI 明确 `大招 = 蜂鸟间谍摄像头`、`V = 猎鹰无人机`（65s）、`G = 脉冲手雷`（55s/2 颗）。
  有攻略站把猎鹰写成大招，属误传。

## 6. 数据可信度

- 深蓝（60s/30s/35s）、露娜（75s/40s/45s）、蜂医（30s/60s/40s）有 2 个以上来源交叉，可信度最高。
- 其余多为单一来源（BWIKI raw 或某一攻略站），建议上线前抽 3–5 个干员进游戏对一次 HUD 秒数。
- 攻略站数值会随赛季平衡变动，**每次大版本更新后重跑一次核对**。

## 7. 还缺的资产

`assets/operators/<id>.png` 目前**都不存在**，需要每个干员一张头像模板图（从 HUD 队友列表底部自己的头像裁切即可，N 张 48–64px 的小图）。
另外建议补 3 个技能图标模板，用于「技能栏位置 + 图标」双保险识别。
